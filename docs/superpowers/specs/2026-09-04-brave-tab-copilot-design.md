## 1. Executive Summary & Problem Statement

Users frequently accumulate 30 to 100+ open tabs in Brave Browser, causing:
1. **Cognitive overload and tab clutter**: Inability to quickly locate active work tabs.
2. **Reading debt & guilt**: Dozens of articles, papers, and tutorials left open indefinitely for "later".
3. **Browser memory pressure**: Background tabs consuming RAM and CPU cycles.

**TabZen (Brave Tab Copilot)** solves this through an AI-powered Brave Side Panel companion that acts as:
- An **AI Tab Organizer**: One-click semantic clustering that groups open tabs into color-coded, labeled native Brave Tab Groups.
- A **Smart Triage Coach ("Tinder for Tabs")**: Prompts users on stale tabs (>24-48 hours old) with instant AI takeaways, read-time estimates, and 1-click decisions (⚡ Instant Summary & Close, 📦 Stash in Vault, ⏳ Snooze).
- A **Zero-FOMO Searchable Vault**: Local searchable storage for closed articles with auto-generated summaries, restore buttons, and 1-click Markdown export to Obsidian/Notion.

## 4. Component Design & Views

### Top Navigation & Header
- Header displays extension logo/title, total open tab count, unread count badge, and a `[⚙️ Settings]` button.
- Three persistent tabs:
  1. **🎯 Triage** (Reading prompter deck)
  2. **📑 Groups** (Active tab list and grouping controls)
  3. **📦 Vault** (Saved articles, search, and export)

### View 1: 🎯 Triage Deck ("Tinder for Tabs")
- Targets tabs where `(Date.now() - tab.lastAccessed) > staleThreshold` (default 24h, configurable).
- Card UI features:
  - Host favicon + page title + domain name.
  - Timestamp indicator (e.g., `Opened 3 days ago`) + Read time (e.g., `5 min read`).
  - **AI Takeaway Card**: 2-sentence summary generated by Gemini Flash.
  - **Action Buttons**:
    - **⚡ Summarize & Close**: Calls Gemini for 3 comprehensive bullet points, saves to Vault, closes tab immediately.
    - **📦 Stash in Vault**: Saves URL + Title + AI snippet to Vault, closes tab immediately.
    - **⏳ Snooze / Keep**: Leaves tab open, moves to the next card in the triage deck.
- Empty State: Celebration message when inbox is zero ("All caught up! Your tab deck is clean.").

### View 2: 📑 Active Groups & Organizer
- **Master Action**: `🪄 Auto-Cluster with AI` button.
  - Gathers all non-pinned, non-internal tabs in the current window.
  - Calls Gemini Flash with tab titles and URLs.
  - Creates native Brave Tab Groups with meaningful titles and appropriate color codes.
- **Group Management Tree**:
  - Displays each group with its color dot, title, and tab count.
  - Actions per group: Expand/Collapse, Rename, and `✕ Close Entire Group`.
  - Displays ungrouped tabs with option to add to an existing group.

### View 3: 📦 Stash Vault & Reading Memory
- **Search Bar**: Real-time filtering across titles, URLs, and summaries.
- **Vault Item List**:
  - Title, URL, date stashed, and AI summary bullets.
  - `[Open Link]` button (reopens in background or active tab).
  - `[Delete]` button (removes from vault).
- **Export Action**:
  - `[📋 Copy as Markdown]` button.
  - `[📥 Download Markdown File]` button generating structured notes compatible with Obsidian and Notion.

### Settings Modal
- Gemini API Key configuration input (stored securely in `chrome.storage.local`).
- Model selector (defaults to `gemini-2.5-flash`).
- Stale threshold selector (12 hours, 24 hours, 48 hours, 7 days).
- Auto-prompt frequency (Daily, or when tabs > 20).

## 5. AI Prompting Strategy & Data Flow

### 1. Semantic Tab Clustering
- **System Prompt**:
  ```text
  You are an expert browser organizer. Group the following list of browser tabs into 3 to 6 logical categories based on topic and workflow.
  Assign each group a concise title (1-3 words, optionally with 1 leading emoji) and a color chosen from: [grey, blue, red, yellow, green, pink, purple, cyan, orange].
  Return valid JSON only matching the schema:
  {
    "groups": [
      {
        "name": "string",
        "color": "string",
        "tabIds": [number]
      }
    ]
  }
  ```
- **Execution**:
  Iterates over returned groups, calls `chrome.tabs.group({ tabIds })`, followed by `chrome.tabGroups.update(groupId, { title, color })`.

### 2. Tab Triage Takeaway
- **Prompt**:
  ```text
  Provide a concise 2-sentence executive summary and estimated reading time for the following webpage:
  Title: {title}
  URL: {url}
  Snippet: {contentSnippet}

  Return valid JSON:
  {
    "takeaway": "string",
    "readTime": "string (e.g. 4 min)"
  }
  ```

### 3. Deep 3-Bullet Summarizer (for Summarize & Close)
- Injects a lightweight DOM extraction script to gather page article text or meta description.
- Calls Gemini Flash to produce 3 key takeaways with actionable highlights.
- Saves payload into `vault.items` in `chrome.storage.local`.

## 6. Storage Schema

Stored under `chrome.storage.local`:
```typescript
interface StorageSchema {
  settings: {
    geminiApiKey: string;
    model: string;            // "gemini-2.5-flash"
    staleHours: number;       // e.g. 24
    tabThreshold: number;     // e.g. 20
  };
  tabStats: {
    [tabId: number]: {
      openedAt: number;
      lastAccessed: number;
    }
  };
  vault: Array<{
    id: string;               // uuid / timestamp
    url: string;
    title: string;
    favIconUrl?: string;
    stashedAt: number;
    takeaway: string;
    summaryBullets?: string[];
    tags: string[];
  }>;
}
```

## 7. Error Handling & Edge Cases

1. **No API Key configured**:
   - Displays a welcoming first-run setup banner in the Side Panel with a direct link to Google AI Studio to obtain a free key.
2. **Gemini API Rate Limits / Network Disconnection**:
   - Graceful inline error messages without breaking the UI.
   - Fallback offline heuristic clustering based on domain names (e.g., grouping all `github.com` tabs together).
3. **Protected & Internal Tabs**:
   - Skips `chrome://`, `brave://`, `devtools://`, and Chrome Web Store tabs from grouping and triage.
4. **Pinned Tabs**:
   - Excluded from stale triage and auto-closing to prevent closing critical pinned tabs.
