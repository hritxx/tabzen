# Brave Tab Copilot (TabZen) - Design Specification

**Date:** 2026-09-04  
**Status:** Approved  
**Target Platform:** Brave Browser / Chromium (Manifest V3)

---

## 1. Executive Summary & Problem Statement

Users frequently accumulate 30 to 100+ open tabs in Brave Browser, causing:
1. **Cognitive overload and tab clutter**: Inability to quickly locate active work tabs.
2. **Reading debt & guilt**: Dozens of articles, papers, and tutorials left open indefinitely for "later".
3. **Browser memory pressure**: Background tabs consuming RAM and CPU cycles.

**TabZen (Brave Tab Copilot)** solves this through an AI-powered Brave Side Panel companion that acts as:
- An **AI Tab Organizer**: One-click semantic clustering that groups open tabs into color-coded, labeled native Brave Tab Groups.
- A **Smart Triage Coach ("Tinder for Tabs")**: Prompts users on stale tabs with instant AI takeaways, read-time estimates, and 1-click decisions (⚡ Summarize & Close, 📦 Stash in Vault, ⏳ Keep Open).
- A **Zero-FOMO Searchable Vault**: Local searchable storage for closed articles with auto-generated summaries, restore buttons, and 1-click Markdown export to Obsidian/Notion.

## 4. Component Design & Views

### Top Navigation & Header
- Header displays extension logo/title, total open tab count, unread count badge, and a `[⚙️ Settings]` button.
- Three persistent tabs:
  1. **🎯 Triage** (Reading prompter deck)
  2. **📑 Groups** (Active tab list and grouping controls)
  3. **📦 Vault** (Saved articles, search, and export)

### View 1: 🎯 Triage Deck ("Tinder for Tabs")
- Targets tabs where `(Date.now() - tab.lastAccessed) > staleThreshold` (default 24h, configurable: 12h / 24h / 48h / 72h / 7d). An `All Tabs` / `Stale` pill toggles the filter.
- Card UI features:
  - Host favicon + page title + domain name.
  - Timestamp indicator (e.g., `2 days ago`) + read time (e.g., `⏱️ 4 min`).
  - **AI Takeaway Card**: 1–2 sentence summary generated by Gemini (250ms debounce + request cancellation when skipping cards fast).
  - **Action Buttons**:
    - **⚡ Summarize & Close**: Calls Gemini for a takeaway + 3 bullet points, saves to Vault, closes tab immediately.
    - **📦 Stash in Vault**: Saves URL + Title + current takeaway to Vault, closes tab immediately.
    - **⏳ Keep Open**: Leaves tab open, moves to the next card in the triage deck.
- Empty State: Celebration message when inbox is zero ("Inbox Zero!").

### View 2: 📑 Active Groups & Organizer
- **Scope toggle**: `Current Window` (default) vs `All Open Windows` (in-place), plus `🪟 Pull & Group All Windows Into This Window` consolidation.
- **Master Action**: `🪄 Organize with AI` button.
  - Gathers manageable (non-internal, non-extension) tabs in scope, including sleeping/discarded tabs *without waking them*.
  - Calls Gemini with tab titles and URLs (offline domain-heuristic fallback when no API key is set).
  - Creates native tab groups with descriptive titles and color codes, dissolving obsolete groups first.
- **Group Management Tree**:
  - Displays each group with its color dot, title, and tab count.
  - Actions per group: `Close Entire Group`; per tab: activate on click, `✕` to close.
  - Displays ungrouped tabs with the same activate/close actions.
  - *Future (not implemented):* expand/collapse toggle, rename, drag-to-group.

### View 3: 📦 Stash Vault & Reading Memory
- **Search Bar**: Real-time filtering across titles, URLs, and summaries.
- **Vault Item List**:
  - Title, URL, date stashed, and AI summary bullets.
  - `[Open Link]` button (reopens in background or active tab).
  - `[Delete]` button (removes from vault).
- **Export Action**:
  - `[📋 Copy as Markdown]` button.
  - `[📥 Download Markdown File]` button generating structured notes compatible with Obsidian and Notion.

### Settings Modal
- Gemini API Key configuration input (stored in `chrome.storage.local`), with show/hide toggle.
- Model selector (default `gemini-3.6-flash`; `🔄 Load Available Models` queries the key for supported models; custom model ID supported).
- Stale threshold selector (12 / 24 / 48 / 72 hours, 7 days).
- *Future (not implemented):* first-run setup banner, auto-prompt frequency (`autoPromptThreshold` is stored but currently unused).

## 5. AI Prompting Strategy & Data Flow

### 1. Semantic Tab Clustering
- Organizes **every** input tab into 2–8 topical groups (prompt instructs 2–8; any tabs the model omits are backfilled via the offline heuristic so coverage is 100%).
- **System Prompt** (see `lib/gemini.js` `clusterTabsWithAI` for the authoritative text): expert-organizer framing, emoji-prefixed 1–3 word titles, no generic bucket names, strict color set, strict JSON schema (`{ groups: [{ name, color, tabIds }] }`).
- **Execution**:
  Iterates over returned groups, calls `chrome.tabs.group({ tabIds })`, followed by `chrome.tabGroups.update(groupId, { title, color })`.

### 2. Tab Triage Takeaway
- Fast takeaway + read-time prompt over title, URL, meta description, and a ≤1500-char page snippet (skipped entirely for sleeping tabs — see `getPageSnippet`). LRU-cached per URL, 1.2s serialized pacing, 250ms card debounce, `AbortController` cancellation, 429 backoff. See `lib/gemini.js` `getTabTakeaway` for the authoritative prompt.

### 3. Deep 3-Bullet Summarizer (for Summarize & Close)
- Same page context at ≤2500 chars; returns takeaway + exactly 3 bullets + read time; saved into `vault` in `chrome.storage.local`. See `getDeepSummary` for the authoritative prompt.

## 6. Storage Schema

Stored under `chrome.storage.local` (see `lib/vault.js` and `background/service-worker.js` for the authoritative shapes):
```typescript
interface StorageSchema {
  settings: {
    geminiApiKey: string;
    model: string;              // e.g. "gemini-3.6-flash"
    staleHours: number;         // e.g. 24
    autoPromptThreshold: number;// stored, currently unused (future auto-prompt)
  };
  tabAccessTimes: {
    [tabId: number]: number;    // last-accessed timestamp ms
  };
  vault: Array<{
    id: string;                 // "vz_" + timestamp + random suffix
    url: string;
    title: string;
    favIconUrl?: string;
    stashedAt: number;
    takeaway: string;
    bullets: string[];
    readTime: string;
  }>;
}
```

## 7. Error Handling & Edge Cases

1. **No API Key configured**:
   - Offline domain-heuristic clustering keeps grouping usable; takeaways fall back to page descriptions/titles. A first-run setup banner is *future work*.
2. **Gemini API Rate Limits / Network Disconnection**:
   - Graceful inline error messages without breaking the UI; quota-cooldown notice on 429 exhaustion.
   - LRU summary cache (no repeat calls), 1.2s request serializer, 250ms card debounce + `AbortController` cancellation, 404 auto-fallback to `gemini-3.6-flash`, exponential backoff with retry on 429.
   - Fallback offline heuristic clustering based on domain names (e.g., grouping all `github.com` tabs together).
3. **Protected & Internal Tabs**:
   - Skips `chrome://`, `brave://`, `devtools://`, and Chrome Web Store tabs from grouping and triage.
4. **Pinned Tabs**:
   - Excluded from stale triage and auto-closing to prevent closing critical pinned tabs.

## 8. Verification & Testing Plan

1. **Load Extension in Brave**:
   - Open `brave://extensions`, enable Developer Mode, click *Load unpacked*, select the repo directory.
2. **Side Panel Trigger**:
   - Click the extension icon in the toolbar or Brave sidebar to verify Side Panel opens correctly.
3. **API Key Setup**:
   - Save a Gemini API key in Settings; optionally use `🔄 Load Available Models` to confirm the key works.
4. **Tab Clustering Test**:
   - Open 15-20 varied tabs (docs, articles, GitHub, YouTube).
   - Click `🪄 Organize with AI`.
   - Verify native tab groups are created with correct colors and descriptive titles.
5. **Triage Deck Test**:
   - Verify tabs appear oldest-first (or filtered by the Stale pill).
   - Test `⚡ Summarize & Close`: verify AI summary is generated, tab closes, and item is added to Vault.
   - Test `📦 Stash Vault`: verify tab closes and link is added to Vault.
   - Test `⏳ Keep Open`: verify card advances without closing.
6. **Vault & Markdown Export Test**:
   - Test search filtering in Vault.
   - Click `[📋 Copy as Markdown]` and `[📥 Download Markdown]`; verify formatted markdown output with title, link, and bullet points.
